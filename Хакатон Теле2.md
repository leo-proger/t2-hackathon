# Тех задание
**Тема** - цифровой помощник для адаптации студентов в учебной деятельности.

Первый курс - тяжело, сложно адаптироваться, фиг пойми что делать, куча вопросов.

Надо **персонализировать** решение под юзера, короче ИИшка, которая выдает точные ответы.

**Принципы**:
- Интерактивность
	- Очень сложно задать вопрос, если ты об этой теме не знаешь. Нужен Q&A формат.
- Геймификация
	- Помогает проще войти в процесс: рейтинговая система, баллы, очки и тд.
- Разрозненность данных
	- Есть куча разных источников, надо все собрать в одно место - в чат боте.
- Нет обратной связи (от студентов как я понял)
	- Студенты не понимают, что от них хотят
	- Студенты выгорают, потому что ничего не понимают - новая система, все новое и тд.
	- Снижение лояльности - меньше доверие, пофигисткое отношение и тд.

**Цель** - создать решение, которая помогает в адаптации.

**Ключевые фичи решения** (***важно***, это критерии оценвания):
- Онбординг с первого дня. Интерактивные чек листы и карты кампуса - чел сразу знает, что делать
- Умные рекомендации. Персональные советы на основе поведения юзера.
- Чат с куратором (тьютором). Быстрая связь с наставником без ожидания очных встреч.
- Геймификация

## Что должно быть на выходе
Формат - **веб приложение** с адаптацией под мобилы и планшеты.

> [!NOTE] 
> Продукт должен быть готов к демонстрации от MVP до весии к внедрению в учебный процесс.

## Критерии оценивания проекта
1. Доступность для ЦА. Продукт прост и понятен для ЦА.
2. Новизна, современность. Крутые идеи, подходы, инструменты, минимализм.
3. Самопрезентация
4. Проработанность. Степень готовности от MVP lо готового продукта

## Как URL отдаем, чтоб юзер сам прочитал
| Что                                      | Почему только URL                       |
| ---------------------------------------- | --------------------------------------- |
| Учебный план / программа                 | Большой PDF, меняется                   |
| Нормативные документы (устав, положения) | Официальный текст, нельзя пересказывать |
| Приказы и объявления                     | Меняются постоянно                      |
| Электронный журнал / портал оценок       | Требует авторизации                     |
| Расписание экзаменов                     | Появляется в конце семестра             |
| Мероприятия и новости                    | Динамика, не стоит парсить              |
|                                          |                                         |
